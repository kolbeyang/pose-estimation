# Phase 1 Plan: Readability -- Docstrings and Skeleton Format Tags

## Overview

Add proper docstrings to every function in the `pose-optimizer/` codebase, and annotate all pose variables with explicit skeleton format tags using the `[DIM:JOINTS]` notation. This makes it immediately clear what joint layout and dimensionality every variable carries as data flows through the pipeline.

## Discussion

### Skeleton Format Tag Vocabulary

Based on the spec (`claude-team/specs/2026-03-30-18-00.md`) and the actual code, here is the complete set of tags:

| Tag | Shape suffix | Meaning |
|-----|-------------|---------|
| `[2D:MEDIAPIPE_33]` | `(33, 2)` | Raw MediaPipe 2D pixel landmarks (all 33 body points) |
| `[3D:MEDIAPIPE_33]` | `(33, 3)` | Raw MediaPipe 3D world landmarks (all 33 body points, hip-relative meters) |
| `[VIS:MEDIAPIPE_33]` | `(33,)` | Raw MediaPipe per-landmark visibility scores |
| `[2D:MPII_16]` | `(16, 3)` | MPII 16-joint 2D keypoints from Stacked Hourglass (x, y, confidence) |
| `[2D:MPII_17]` | `(17, 3)` | MPII remapped to 17-joint intermediate (via `mpii_to_skeleton`, before head strip) |
| `[3D:MOTIONBERT_17]` | `(17, 3)` | MotionBERT raw 3D output, 17 joints (before head strip) |
| `[HEATMAP:MPII_16]` | `(16, 64, 64)` | Stacked Hourglass heatmaps in MPII 16-joint order |
| `[2D:SKELETON_16]` | `(16, 2)` | 2D pixel coordinates in the optimizer's 16-joint skeleton order |
| `[3D:SKELETON_16]` | `(16, 3)` | 3D positions in the optimizer's 16-joint skeleton order |
| `[VIS:SKELETON_16]` | `(16,)` | Per-joint visibility/confidence in 16-joint skeleton order |
| `[HEATMAP:SKELETON_16]` | `(16, 64, 64)` | Synthetic heatmaps in 16-joint skeleton order (for MediaPipe) |
| `[3D:COCO19]` | `(19, 3)` | CMU Panoptic COCO19 ground truth (19 joints, world coords, centimeters) |
| `[3D:SKELETON_16_EVAL]` | `(14, 3)` | Eval-only subset (14 of the 16 joints, indices from `EVAL_JOINTS`) |
| `[FK_PARAMS]` | varies | FK parameters: root_pos `(3,)`, root_rot `(3,)`, local_rots `(16, 3)`, bone_lengths `(16,)` |

**Skeleton 16-joint order** (the optimizer's canonical format): Pelvis(0), RHip(1), RKnee(2), RAnkle(3), LHip(4), LKnee(5), LAnkle(6), Spine(7), Neck(8), Head(9), LShoulder(10), LElbow(11), LWrist(12), RShoulder(13), RElbow(14), RWrist(15).

- Category 1 (12 Eval joints): indices 1-6, 10-15
- Category 2 (2 Synthesized): indices 0 (Pelvis), 8 (Neck)
- Category 3 (Optimization-only): index 7 (Spine, FK-internal), index 9 (Head -- Head Top for MotionBERT, Nose for MediaPipe)
- `EVAL_JOINTS = [0,1,2,3,4,5,6,8,10,11,12,13,14,15]` (14 joints: Cat1 + Cat2, excludes Spine and Head)

### Where Format Conversions Happen

1. **MPII_16 -> MPII_17 -> SKELETON_16**: `skeleton.py:mpii_to_skeleton()` converts `[2D:MPII_16]` (16,3) to (17, D), then `strip_head_joint()` removes index 10 to produce `[2D:SKELETON_16]` or `[3D:SKELETON_16]`. Used in `run_motionbert/detect.py`.

2. **MEDIAPIPE_33 -> SKELETON_16**: `skeleton.py:mediapipe_to_skeleton()` maps 33 landmarks to 16-joint skeleton. Synthesizes Pelvis (midpoint hips), Neck (midpoint shoulders), Spine (midpoint Pelvis+Neck). Used in `run_mediapipe/detect.py`.

3. **COCO19 -> SKELETON_16**: `skeleton.py:coco19_to_skeleton()` maps 19-joint GT to 16-joint skeleton. Spine is synthesized as midpoint(Pelvis, Neck). Used in `cmu_data.py:load_ground_truth_sequence()`.

4. **MOTIONBERT_17 -> SKELETON_16**: `strip_head_joint()` in `run_motionbert/detect.py:run_motionbert()` removes the duplicate head joint after MotionBERT 3D lifting.

5. **SKELETON_16 -> camera space**: `motionbert_to_camera_space()` and `mediapipe_3d_to_camera()` convert detector-relative 3D to absolute camera-space meters. Both produce `[3D:SKELETON_16]`.

6. **SKELETON_16 -> SKELETON_16_EVAL**: `evaluate.py:evaluate()` slices with `EVAL_JOINTS` to get the 14 eval joints.

7. **SKELETON_16 -> HEATMAP:MPII_16 mapping**: `scoring.py` uses `SKELETON_TO_MPII_HEATMAP` to map skeleton joint indices to MPII heatmap channel indices when scoring against SH heatmaps.

### Implementation

#### 1. `pose-optimizer/skeleton.py`

- **Module docstring**: Update to describe the 3-category joint system (12 Eval, 2 Synthesized, Optimization-only) and reference the spec.
- **`mpii_to_skeleton()`**: Docstring should state input is `[2D:MPII_16]` (16, D) and output is `(17, D)` intermediate (pre-strip). Add inline comment `# [2D:MPII_17]` or `# [3D:MPII_17]` after `skel` declaration. Clarify this is an intermediate format and `strip_head_joint` must be called after.
- **`strip_head_joint()`**: Docstring should state it converts `(17, D)` intermediate to `[*:SKELETON_16]` by removing duplicate head joint at index 10.
- **`coco19_to_skeleton()`**: Input docstring: `[3D:COCO19]` (19, 3). Output: `[3D:SKELETON_16]` (16, 3). Note that Spine is synthesized as midpoint.
- **`mediapipe_to_skeleton()`**: Input: `[2D:MEDIAPIPE_33]` or `[3D:MEDIAPIPE_33]` (33, D). Output: `[2D:SKELETON_16]` or `[3D:SKELETON_16]` (16, D). Note Cat2 joints (Pelvis, Neck) are midpoints, Spine is midpoint of midpoints.

### Inline Tag Convention

For variable declarations, place the tag as an end-of-line comment:

```python
kp_2d = mediapipe_to_skeleton(mp_2d)  # [2D:SKELETON_16]
```

For batched/list variables:

```python
det_cam_positions: list[np.ndarray] = []  # list of [3D:SKELETON_16] (16, 3), camera-space meters
```

For function returns documented in docstrings, use the tag inline in the Returns section:

```python
"""
Returns:
    keypoints_2d: List of (16, 2) pixel coordinates. [2D:SKELETON_16]
    keypoints_3d: List of (16, 3) world coordinates. [3D:SKELETON_16]
    visibility: List of (16,) visibility scores. [VIS:SKELETON_16]
"""
```

   ```bash
   uv run python -c "
   import inspect, importlib, sys
   sys.path.insert(0, 'pose-optimizer')
   for mod_name in ['skeleton', 'camera', 'config', 'cmu_data', 'evaluate', 'scoring', 'fk', 'overlay_video']:
       mod = importlib.import_module(mod_name)
       for name, obj in inspect.getmembers(mod, inspect.isfunction):
           if not name.startswith('_'):
               assert obj.__doc__, f'{mod_name}.{name} missing docstring'
   print('All public functions have docstrings')
   "
   ```

