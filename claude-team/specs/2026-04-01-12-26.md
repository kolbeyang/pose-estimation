## Proposed revised config

`data_root` (string, default: "./data/panoptic-toolbox")
Path to the panoptic dataset directory. 

`examples` (list, default: [])
Explicit list of windows to process. Each entry is:
`{"sequence": "171204_pose1", "camera": "00_00", "start_frame": 1000, "num_frames": 150, "person_idx": 0}`
If the list is empty (or omitted), the pipeline auto-discovers all sequence subdirectories in data_root and processes every sequence from frame 0 to end, camera 00_00, person 0.

`output_dir` (string or null, default: null)
Where to write output. If null, defaults to the existing output/ directory with an auto-generated timestamped subdirectory.

`generate_graphs` (bool, default: true)
Whether to generate the per-example graphs (trajectory, loss curve, MPJPE plots, etc.). Disable for large evaluation runs.

`generate_video` (bool, default: true)
Whether to generate the overlay heatmap video per example. Disable for large evaluation runs.

`target_fps` (float, default: 10.0)
Frame sampling rate from the 30fps source video.

`optimization` (object)
Adam optimizer hyperparameters Ñ unchanged from current.

`sh_batch_size` (int, default: 32, motionbert only)
Stacked Hourglass inference batch size.

`motionbert_conf_threshold` (float, default: 0.0, motionbert only)
Confidence threshold for zeroing low-confidence MotionBERT keypoints.
