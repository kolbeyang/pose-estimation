### Category 3: Synthesized Joint

Motionbert doesn't have a nose keypoint so we need to synthesize a nose keypoint purely for the purpose of initializing our optimizer.

Let's initialize motionbert nose keypoint as 30 percent of the way from base of neck to top of head.
```
nose = base_of_neck + (top_of_head - base_of_neck) * 0.3
```

### `main.py`

Rough pseudocode (nonbinding)
```
def main(config):
    examples = load_examples(config)
    heatmaps = get_heatmaps(examples)
    
    if config.motionbert:
        motionbert_raw_predictions = run_motionbert(heatmaps)
        motionbert_optimized_predictions = run_optimizer(motionbert_raw_predictions, heatmaps)
        evaluate_motionbert(heatmaps, motionbert_raw_predictions, motionbert_optimized_predictions, config)
    if config.mediapipe:
        mediapipe_raw_predictions = run_mediapipe(examples)
        mediapipe_optimized_predictions = run_optimizer(mediapipe_raw_predictions, heatmaps)
        evaluate_mediapipe(heatmaps, mediapipe_raw_predictions, mediapipe_optimized_predictions, config)

    evaluate_aggregate(...all_necessary_info)
    

```

1. **Determine input**
The config already defines which input examples should be processed. It also allows for input to be loaded from an arbitrary folder. This is important because we will be running on many large examples for our final evaluation.

2. **Get 2D heatmaps**
Run input examples (batched if possible for speed) through YOLO -> StackedHourglass yielding heatmaps.

3. **Get base model 3d predictions**
Run Mediapipe and/or Motionbert depending on the config

**Motionbert**
StackedHourglass heatmaps -> Motionbert -> 3d predictions -> Shared optimizer(3d predictions, heatmaps, etc.)

**Mediapipe**
Input videos -> Mediapipe -> 3d predictions + StackedHourglass heatmaps -> Shared optimizer(3d predictions, heatmaps, etc.)

There is a special step in the Mediapipe where we use solvePnp to get camera coordinates. This uses the 2d landmarks from Mediapipe. Although the optimizer will use StackedHourglass heatmaps on the Mediapipe pipeline as well, at this step for finding camera coordinates it is okay to use 2d landmark straight from MediaPipe predictions.

## Phase 2: Evaluatino metrics should not be root relative
It seems that we are calculating all evaluation metrics relative to the root. This is cheating. I can tell because the pose error for the root joint (pelvis) is always 0 which indicates we are doing rot-relative evaluation.

## Phase 3: Add a new evaluation metric

This is in addition to the metrics outlined in this spec.
agent-team/specs/motionbert-mediapipe-combined.md

### 2d Reprojected MPJPE: Mean Per-Joint Position Error
**INPUT**: 
- Predicted trajectory: (N, K, 3)
- Ground truth trajectory: (N, K, 3)
- Keypoint visibility scores: (N, K)
**OUTPUT**: 
- Score

Reproject the predicted trajectory and the ground truth trajectories back down to the 2d frame. Only include points that are within the frame boundaries (should be equivalent to the keypoint visibility scores with the way those are calculated). 

Calculate the mean of the distances between each keypoint projected down to 2d and the ground truth keypoint projected down to 2d measured in pixels.

## General testing tips
The exact testing methodology required will vary based on the exact phase of development you are working in, but here are some general guidelines.

### Time investment
An important principle to adhere to is 
```
Time investment should be proportional to confidence it will work
```
This means at the beginning, run very very rough tests. As your confidence grows in a particular piece of functionality, it is okay to run on 3 examples, 5 examples, 10 examples etc.

### Heatmap videos
The heatmap videos generated with each run by default provide strong signal as to what is happening within the models.

In order to effectively analyze them, use pillow or ffmpeg to extract a frame from midway through the video. Analyze this still image and particularly analyze how the following elements are placed relative to one another:
- The actual human subject of the video
- The heatmap overlays
- The ground truth skeleton
- The raw base model skeleton
- The optimizer's predicted skeleton

### Evaluation metrics
Use the evaluation metrics to judge the quality of the current run. Of course the main evaluation metric you should focus on is the VW-SI-MPJPE.
