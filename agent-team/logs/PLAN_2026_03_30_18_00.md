### Fix stretched MediaPipe heatmaps (Phase 2)

In `scoring.py:generate_synthetic_heatmaps()`, the sigma is converted from pixel space to heatmap space using only `sx` (line 367: `sigma_hm = sigma / sx`). When the image is non-square (e.g., 1080x1920), `sx != sy`, so the Gaussian in heatmap space uses a single sigma for both axes, producing an ellipse when the aspect ratio differs.

Fix: compute `sigma_hm_x = sigma / sx` and `sigma_hm_y = sigma / sy` separately, and use `(xx - cx_hm)**2 / (2 * sigma_hm_x**2) + (yy - cy_hm)**2 / (2 * sigma_hm_y**2)` in the exponent.
