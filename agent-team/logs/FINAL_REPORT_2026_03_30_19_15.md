## What Was Done

### 1. Directory Renames
Simple `git mv`:
- `mediapipe/` → `run_mediapipe/` (all Python files stay inside)
- `motionbert/` → `run_motionbert/` (all Python files stay inside)
- Entrypoints: `mediapipe.py` → `run_mediapipe.py`, `motionbert.py` → `run_motionbert.py`

The mediapipe package name collision is eliminated. The `sys.path`/`sys.modules` hack in `run_mediapipe/detect.py` was removed — now uses plain `import mediapipe as mp`.

### 2. Self-Containment
Removed all fallback paths to `../../mediapipe-pose` and `../../motionbert-pose`. Model checkpoints stay in `run_motionbert/checkpoints/`. MotionBERT cloned repo stays in `run_motionbert/external/MotionBERT/`. MediaPipe model stays in `run_mediapipe/`.

### 3. Joint Mapping Overhaul
- Renamed all `h36m` references to `skeleton` throughout: `mpii_to_skeleton`, `coco19_to_skeleton`, `mediapipe_to_skeleton`, `SKELETON_TO_MPII_HEATMAP`, etc.
- Joint names updated: Hip→Pelvis, Thorax→Neck, Neck→Head
- `EVAL_JOINTS` expanded from 12 to 14 (added Pelvis and Neck/BaseOfNeck)
- `mpii_to_skeleton`: Pelvis uses MPII[6] directly, Spine uses MPII[7] directly — no midpoint computation
- `SKELETON_TO_MPII_HEATMAP`: all 16 joints now have MPII indices (no more `None` entries)

### 4. Stretched Heatmap Fix
`scoring.py:generate_synthetic_heatmaps()` uses separate `sigma_hm_x` and `sigma_hm_y` so Gaussians are circular in pixel space for non-square images.

### 5. Projection Tests
19 new tests in `experiment/test_projection.py` using real CMU Panoptic camera parameters. Covers camera projection, torch/numpy consistency, world-camera roundtrips, heatmap peaks, and the non-square heatmap fix.

### 6. Cleanup
- Deleted `compare.py` (stale)
- Removed backward-compat camera aliases
- Removed unused imports
- Updated README.md to match new naming

## Critical Decisions

### 1. Entrypoint Rename (`mediapipe.py` → `run_mediapipe.py`)
The initial implementation kept `mediapipe.py` at the project root, which still shadowed the pip `mediapipe` package. Eve caught this — renamed to `run_mediapipe.py`.

### 2. Single Skeleton with Updated Names (Not Dual-Skeleton)
Rather than creating separate `MOTIONBERT_SKELETON` and `MEDIAPIPE_SKELETON` configs, the implementation updated the existing single skeleton: renamed joints, expanded EVAL_JOINTS to 14, removed midpoint computations from `mpii_to_skeleton`. This is simpler and matches the user's preference for minimal changes.

### 3. h36m in Checkpoint Filename
`motionbert_lite_h36m.bin` is an upstream model file — can't be renamed. Flagged as a known exception.
