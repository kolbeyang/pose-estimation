# Phase 3 Report: Model Loading Optimization

**Developer:** Dan
**Date:** 2026-03-31

## Summary

Refactored both the MotionBERT and MediaPipe pipelines to load ML models once at pipeline startup and reuse them across all examples via explicit dependency injection.

## Changes

### `pose-optimizer/run_motionbert/detect.py`
- Added `MotionBertModels` dataclass holding YOLO, Stacked Hourglass, MotionBERT models and device
- Added `load_all_models()` factory function that loads all three models once
- Modified `detect_person_bbox()` to accept optional `yolo` parameter
- Modified `run_hourglass()` to accept optional `model` and `device` parameters
- Modified `run_motionbert()` to accept optional `model` and `device` parameters
- Modified `detect_poses()` to accept optional `models: MotionBertModels` parameter
- All functions fall back to loading models internally when not provided (backward-compatible)

### `pose-optimizer/run_motionbert/__init__.py`
- Updated import to include `MotionBertModels` and `load_all_models`
- `run_pipeline()` now calls `load_all_models()` once before the example loop
- `process_example()` accepts optional `models` parameter and passes it to `detect_poses()`

### `pose-optimizer/run_mediapipe/detect.py`
- Added `load_landmarker()` function that creates a reusable `PoseLandmarker`
- Modified `detect_poses()` to accept optional `landmarker` parameter
- When landmarker is provided externally, it is NOT closed by `detect_poses` (caller owns lifecycle)
- When no landmarker is provided, one is created and closed internally (backward-compatible)

### `pose-optimizer/run_mediapipe/__init__.py`
- Updated import to include `load_landmarker`
- `run_pipeline()` now calls `load_landmarker()` once before the example loop and `landmarker.close()` after
- `process_example()` accepts optional `landmarker` parameter and passes it to `detect_poses()`

## Verification

Both pipelines tested with 2-example configs (30 frames each, 3 optimization steps):

- **MediaPipe**: "Loaded MediaPipe PoseLandmarker" appears exactly once. Both examples processed successfully with correct metrics.
- **MotionBERT**: "Loaded YOLOv8n", "Loaded Stacked Hourglass", "Loaded MotionBERT-Lite (global)", "All models loaded on mps" appear exactly once. Both examples processed successfully.
- No model loading messages appear during per-example processing.
- Backward compatibility preserved: all new parameters default to None, triggering internal loading when not provided.

## Design Decisions

- Used optional parameters (defaulting to None) rather than required parameters for backward compatibility
- No global state or singletons -- all model references passed explicitly
- MediaPipe landmarker lifecycle managed by `run_pipeline` (load before loop, close after loop)
- MotionBERT models owned by `run_pipeline` scope (garbage collected when function returns)
